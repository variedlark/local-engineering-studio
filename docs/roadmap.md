# Product Roadmap

This roadmap captures high-impact improvements that move the project toward a
publicly consumable product.

## Near term

- multi-select and lasso selection over current interactive canvas
- richer route visualization and diagnostics
- expanded quality suite with trend history
- UI integration tests for critical workflows

## Mid term

- first-run onboarding flow and sample projects
- plugin system for custom analyses/exporters
- deeper offline package distribution for desktop releases

## Long term

- collaborative import/export formats
- advanced solver integration
- domain-specific template libraries
