# Support

## Getting Help

- Read `README.md` for setup and quality commands.
- Read `docs/how-to-use.md` for workflow guidance.
- Read `docs/contributor/contributing.md` before contributing.

## Reporting Bugs

Open a GitHub issue and include:

- platform and versions (OS, Rust, Node, pnpm)
- exact steps to reproduce
- expected vs actual behavior
- relevant logs or screenshots

## Feature Requests

Open a GitHub issue and include:

- user problem and target workflow
- why existing behavior is not sufficient
- acceptance criteria for the feature
